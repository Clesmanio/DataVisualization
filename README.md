# Imigração para o Canadá · Visualização de dados

Notebook de estudo sobre a imigração para o Canadá entre 1980 e 2013. O exercício explora registros de 195 países e usa o Brasil como exemplo para analisar a evolução da série anual.

## O que o notebook mostra

- Leitura e inspeção da base com pandas.
- Preparação da série por ano e extração dos dados do Brasil.
- Construção de gráficos com Matplotlib, Seaborn e Plotly.

## Como explorar

Abra o [notebook](./datavisualization.ipynb) no GitHub para ler o código e consultar as saídas salvas. Para executar as células em Jupyter ou Colab, instale `pandas`, `matplotlib`, `seaborn` e `plotly` e obtenha a base `imigrantes_canada.csv` usada no exercício. O CSV não está incluído neste repositório. A primeira célula de leitura aponta para `/content/imigrantes_canada.csv`, caminho que pode ser ajustado conforme o ambiente.
